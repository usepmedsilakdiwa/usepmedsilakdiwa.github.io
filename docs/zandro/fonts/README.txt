FONT FILES TO DOWNLOAD AND PLACE IN THIS FOLDER

1. Manrope Variable — use for headings, project titles, navigation and display labels.
   Expected filename: Manrope-Variable.woff2
   Recommended source: Google Fonts (Manrope), download the variable WOFF2 file.

2. DM Sans Variable — use for paragraphs, descriptions, buttons and metadata.
   Expected filename: DMSans-Variable.woff2
   Recommended source: Google Fonts (DM Sans), download the variable WOFF2 file.

The site falls back to Arial if these files are not present. WOFF2 is recommended for websites;
TTF can be converted to WOFF2 if necessary. Update css/silakdiwa.css if you choose different filenames.
